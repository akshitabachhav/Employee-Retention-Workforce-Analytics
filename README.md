# Employee Retention & Workforce Analytics System

## Project Overview
An end-to-end data analytics project designed to analyze employee attrition, identify workforce trends, and generate actionable HR insights using Python, SQL, and Power BI.

## Objectives
- Analyze employee attrition and retention patterns.
- Identify workforce trends across departments, job roles, age groups, and salary bands.
- Understand the relationship between overtime, job satisfaction, and employee attrition.
- Build an interactive dashboard to support data-driven HR decisions.

## Tools & Technologies
- **Python:** Data cleaning, preprocessing, and exploratory data analysis.
- **Pandas:** Data manipulation and analysis.
- **SQL / MySQL:** Database management and workforce analysis.
- **Power BI:** Interactive dashboard and data visualization.
- **DAX:** KPI calculations and measures.
- **Power Query:** Data transformation.

## Project Workflow
1. Data loading and inspection.
2. Data cleaning and preprocessing using Python.
3. Exploratory data analysis and visualization.
4. Employee data analysis using SQL.
5. Dashboard development using Power BI.
6. Workforce insights and interpretation.

## Key Performance Indicators
- Total Employees: 1,470
- Active Employees: 1,233
- Employees Left: 237
- Attrition Rate: 16.12%
- Retention Rate: 83.88%

## Key Insights
- Employees working overtime have a higher attrition rate.
- Employees in the Sales department show higher attrition than other departments.
- Early-career employees show comparatively higher attrition.
- Lower salary bands experience higher attrition.

## Power BI Dashboard
The interactive dashboard includes KPI cards, slicers, and visualizations covering:
- Attrition by overtime
- Attrition by tenure
- Job satisfaction
- Gender
- Work-life balance
- Job role
- Age group
- Department
- Salary band
